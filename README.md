## 一、真实会场的四大痛点与破局之道

在涉外圆桌、高管汇报和跨国学术研讨的高压现场，同传软件稍有失误就会变成灾难。Harry Translate 针对现场四个最典型的抓狂时刻交出了硬核工程答卷：

| 现场痛点场景 | 传统同传工具的抓狂体验 | Harry Translate v4.0.0 的物理级解法 |
| :--- | :--- | :--- |
| **痛点 1：视觉频闪与心理晃动** | 发言时变深变黑、静默时变淡消失。整场会议屏幕如同故障灯泡忽明忽暗，严重分散演讲者与听众的注意力。 | **腾讯会议级绝对稳态（$\Delta\text{opacity} \equiv 0.0$）**<br>彻底移除透明度动态计时器与系统级毛玻璃绑定；定稿文字永久静止驻留，新句平滑无缝覆盖，杜绝视界黑屏与突现断层。 |
| **痛点 2：非激活悬浮窗“装聋作哑”** | 为了打字不抢输入焦点做成非激活面板，但鼠标滑上去时顶栏按钮毫无反应，非要“先点一下唤醒窗口”才能操作。 | **Cocoa 原生全域追踪与 0px 贴顶近距微感知**<br>底层注入 `NSTrackingActiveAlways` 全时监听，彻底抹平顶部边缘死区。光标掠过顶端 0 像素物理边缘，控制胶囊自如浮现，首击即响应。 |
| **痛点 3：视距差异与小窗口切字** | 笔记本上看合适，投到几十米外的 4K 大屏字小如蚁；拉扁贴在 PPT 底部时，下半截汉字笔画直接被边框削掉。 | **三档响应式阶梯字号与 PPT 视口破锁放大**<br>`🔤 标准 / 大号 / 特大` 随心切；当视口高度 $\le 75\text{px}$ 时，引擎智能破锁放大，GPU 硬件加速向上平滑托举，保留呼吸留白，零切字。 |
| **痛点 4：双语混流与专有名词翻车** | 双向发言时外宾屏幕突然冒出一串中文；前沿专词（LoRA、单抗）被听成同音谐音字；云端塞多了词库直接报错断网。 | **广播层双语对称镜像、纯度锁与 18,449 词离线纠偏**<br>外宾端严密筑牢纯度防火墙，杜绝中文字符渗入；云端热词精炼为 48 词动态更新帧，本地 0.0058ms 自动机全量挂载万级词库毫秒纠偏。 |

## 二、五大感官级核心黑科技展台

### 1. 空间美学与视窗自由：Apple VisionOS 液态微透凝胶拟态

它不是贴在屏幕上的一块死板色块，而是一枚晨雾中凝结的水晶棱镜。

- **微透凝胶质感**：采用 `backdrop-filter: blur(20px) saturate(190%) contrast(102%)`，辅以出厂默认 `💧 15%` 微透凝胶底色。顶部仅 1 像素宽的微米级镜面高光棱镜（`inset 0 1px 0 rgba(255, 255, 255, 0.18)`），在光影流转中折射出一抹极细的冷光。无论底衬是刺眼的纯白 PPT、暗黑代码编辑器，还是绚丽的演讲视频，字幕都像雕塑般浮空悬立，不脏不飘；
- **百万级豪车电吸门般的顶栏微感知**：无需点击激活窗口，鼠标滑入顶端 0~46px 缓冲区，语言胶囊、调色胶囊、字号胶囊与物理锁自如滑出；光标移开即刻轻柔隐入空气，行云流水；
- **120 FPS 原生硬件拖拽与金属拉伸角标**：按住左侧微型点阵把手（`⠿`），macOS WindowServer 原生硬件接管，0 CPU 占用跨屏漫游；右下角金属三段点阵角标（`⋱`）支持任意无级伸缩。

### 2. 视界收放自如：3 级阶梯响应字号与 PPT 视口破锁自适应

无论是小屏笔记本随身提词，还是 4K 大屏投向数十米开外的会场后排，文字都能找到最舒展的姿态。

- **三档阶梯字号矩阵**：
  - **`🔤 标准`**：主译文 19px / 辅原文 15px（小视口紧凑包络 15px / 12px），日常办公与笔记本近视距出厂默认；
  - **`🔤 大号`**：主译文 24px / 辅原文 18px（小视口智能破锁至 20px / 15px），适配 27~32 寸 4K 桌面显示器；
  - **`🔤 特大`**：主译文 29px / 辅原文 21px（小视口智能破锁至 24px / 17px），专为大型涉外宣讲、远程投影或会务提词打造；
- **PPT 扁平视口破锁与 GPU 平滑托举**：当窗口被压成极扁的字幕条置于 PPT 底部（高度 $\le 75\text{px}$）时，排版引擎果断破除紧凑束缚，由硬件加速自动将文字向上平滑微移，保留底部 $\ge 1.5\text{px}$ 安全呼吸留白，汉字笔画 100% 完整可见；
- **历史定稿行（`#pastLine`）恒定 14px**：换句时上一句定稿文字自动锚定在上方，字号固定为 14px（紧凑模式 12px），无论主字号如何放大，对下方主译文与原文辅助区的高度侵占严格为 0px；
- **秒级调节与持久记忆**：按下快捷键 **`Cmd + Shift + F`**（Windows **`Ctrl + Shift + F`**）一键循环轮转，亦支持 `Cmd/Ctrl + =/-` 无级伸缩，配置以 `qwen_hud_font_tier` 键写入 `localStorage`，重启视窗自动恢复。

### 3. 外交级严谨：双悬浮窗广播层镜像与目标语言纯度锁

圆桌跨国谈判双方密集交替发言时，两只悬浮窗就像两面精准对调的光学分棱镜。

- **双语对称广播镜像**：在双悬浮窗模式（`--dual`）下，服务端在 WebSocket 广播层实现对称分发（对象属性严格物理隔离）。中方发言时，我方视窗大字看英文、外宾视窗大字看中文，信息分秒同步对齐；
- **目标语言纯度防火墙 (`sanitizeTargetForChannel`)**：在数据出口处焊死字符级语种纯度硬锁。外宾端的中译英窗口即使遭遇环境噪音突发干扰，也会在毫秒间滤除一切中文字符，呈现在外宾眼前的永远是地道纯净的外语字幕；
- **双阶微停顿合并（300ms/450ms）**：微停顿（$\le 300\text{ms}$）自动无缝合并至同段，段落停顿（$> 450\text{ms}$）平滑保持前文视觉焦点，新句首包到达前杜绝黑屏闪烁；
- **单向监听立省 50% Token**：客户端感知门控（Client-Aware Stream Gating）自动阻断未被监听的通道音频直推，单向收听场景下直接削减 50% 的云端 API Token 消耗。

### 4. 远场声学与极速断句：1~2 米自适应软限幅 AGC 与 240ms Server VAD

电脑放在会议桌中央，距离发言人 1~2 米拾音发弱？音频流水线自带“录音棚母带师的无形之手”。

- **微秒级自适应软限幅 AGC**：在 50ms 微切片热路径中内嵌 C 级自适应增益算法（单帧耗时仅 **0.0023ms / 2.3µs**）；
- **动态能量温和提振（最高 3.2x）**：自动监测环境底噪并设立动态静音门限（`noise_floor = 240.0`），对 1~2 米弱声发言温和施加最高 3.2 倍能量补偿（`target_rms = 1200.0`），大幅提升微弱拾音在声学模型中的信噪比与识别率；
- **双曲正切软限幅（$\tanh$ Soft-Knee）**：大声激动凑近麦克风时，双曲正切曲线如记忆海绵般把波峰平滑收拢在 $\pm 31500$ 线性包络内，杜绝近身削顶爆音；
- **240ms 云端极速断句与主动 Commit**：云端 `server_vad` 调优至 240ms 极速断句，配合 DashScope `stash` 实时尾词跟手；持续语音满 2.4s 遇能量低谷（RMS < 380）或满 3.8s 强制上限主动发送 Commit 截句，语流切分自然利落。

### 5. 专业尊严护城河：18,449 词分类银行与双轨智能防爆分发

针对云端 API 只要超过 1,000 词就会报错挂断的脆弱边界，系统构筑了双轨分发闸门。

- **前沿 48 组轻装战术卡**：动态增量会话更新帧严格限幅在 $\le 48$ 词（UTF-8 配置包 $< 2.5\text{KB}$），毫秒级下发，彻底消除大词库 Attention 预填充拖慢音频上行；
- **全库安全保护线（$\le 900$ 词）**：首次建连或全量导出时锁定 900 词安全阈值，预留 10% 缓冲空间，100% 杜绝触碰云端 1,000 词硬上限导致的 `InvalidParameter` 断线；
- **后方 1.8 万卷本地离线百科全书**：本地纯 Python Aho-Corasick 词法自动机全量挂载全部 18,449 条专业术语与 ASR 谐音纠偏规则。单句全库扫描仅耗时 **0.0058ms（5.8 微秒）**，在毫秒间精准将“落拉”矫正为“LoRA”、“库伯内特斯”还原为“Kubernetes”，守护高精尖学术与商务会议的专有名词底线，且 0 额外 Token 消耗。

## 五、跨平台 5 分钟极速开箱 (Quickstart)

### Part 1: macOS 部署与极速启动

#### 1. 基础环境安装
打开 macOS「终端」（Terminal）：
```bash
# 1. 安装 Homebrew (若已安装请跳过)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 安装 Python 3.11 与音频底层依赖库
brew install python@3.11 portaudio git
```

#### 2. 初始化项目运行环境
克隆公开仓库并创建专属隔离虚拟环境：
```bash
git clone https://github.com/xiaokunshi5-lang/harry-translate.git
cd harry-translate

python3.11 -m venv .venv
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

#### 3. 配置虚拟回环声卡（BlackHole 2ch）
> **说明**：若只需翻译自己的麦克风发言，此步骤可跳过；若需录制翻译 Zoom、腾讯会议、Teams 中对方的声音，需配置内录。
```bash
brew install blackhole-2ch
```
打开系统「音频 MIDI 设置」（Audio MIDI Setup）：
1. 点击左下角 `+` 号，选择 **「创建多输出设备」**；
2. 同时勾选 **「BlackHole 2ch」** 与您平时听音的 **「物理耳机或扬声器」**（耳机设为主设备并勾选漂移校正）；
3. 系统与会议软件的声音输出选择此「多输出设备」即可。

#### 4. 授权麦克风与配置 API Key
1. 打开 Mac「系统设置」 -> 「隐私与安全性」 -> 「麦克风」，允许「终端」或「Python」访问；
2. 复制配置文件模板并填入您的 DashScope API Key：
   ```bash
   cp .env.example .env
   # 编辑 .env 文件，将 DASHSCOPE_API_KEY 替换为您的有效 API Key
   ```
3. 在访达中双击运行 **`启动悬浮同传.command`** 即可即刻起航！

├────────────────────────────────────────────────────────────────────────┤

└────────────────────────────────────────────────────────────────────────┘

内置 15 个标准化模块化词包，涵盖 154 条 ASR 同音错字纠正规则、9,039 条中译英术语规则以及 9,256 条英译中术语规则，词条总数达 **18,449 条**。

### 2. 抽屉式可视化工作台 (`#config-drawer`)

在大屏控台页面（`http://localhost:8000/` 或 `/split`）中：
1. **呼出工作台**：轻点顶部控制栏绿色按钮 **`📚 会议热词`**（或点击 `⚙️ 系统基础配置`）；
2. **观察配额水位仪**：顶部实时监测云端配额水位进度条与健康度状态（`optimal` $\le 750$ 词、`warning` $751 \sim 900$ 词、`capped` $> 900$ 词智能分流）；
3. **按需勾选标签**：在标签区随心勾选本场会议适用的领域分类（如勾选「🧬 生物医药与临床」），即刻毫秒级热生效；
4. **导入嘉宾名单**：在「批量快加」面板粘贴外宾姓名，一键导入至本场临时词（P0 绝对最高覆盖）；
5. **会后纯净清空**：散会后轻点「🧹 一键清空本场临时词」，内存瞬间重置，磁盘零污染。
