## 1. 背景与核心原理

### 为什么常规麦克风无法拾取远程会议声音？

macOS 与现代 Windows 系统具备严格的音频硬件隔离与隐私沙箱机制：

- 笔记本自带麦克风或外接耳机麦克风只能采集**空气中振动的物理声音**（如您自己的说话声）。
- 远程外宾与参会者的声音直接由系统混音器通过数字信号输出到您的**耳机或扬声器**中，默认不会回路重定向至麦克风输入轨。

### 解决架构：虚拟音频管道 (Loopback Pipeline)

通过虚拟音频回环驱动（macOS 上的 **BlackHole 2ch** 或 Windows 上的 **立体声混音 / VB-CABLE**），我们可以构建一条分流管道：

```text
[会议软件: Zoom / 腾讯会议 / Teams / 飞书]
                   │
                   ▼ (音频播放输出)
       ┌───────────────────────────┐
       │     多输出设备 / 混音器     │
       └─────────────┬─────────────┘
                     ├───► [物理耳机 / 扬声器] (您的人耳实时监听会议，无延迟)
                     │
                     └───► [虚拟声卡 BlackHole 2ch / VB-CABLE]
                                     │
                                     ▼ (音频录制输入)
                       [Qwen 悬浮同传 AudioCaptureManager]
                                     │ (16kHz 单声道 PCM)
                                     ▼
                        [阿里云百炼实时翻译引擎]
                                     │ (流式返回)
                                     ▼
                       [Apple 悬浮 HUD 双行字幕展现]
```

## 2. macOS 配置指南 (BlackHole 2ch + 多输出设备)

### 步骤 1：安装 BlackHole 2ch 虚拟声卡驱动

BlackHole 是 macOS 平台上轻量、开源、低延迟（零 CPU 消耗）的现代虚拟音频驱动。

- **方式 1 (推荐，通过 Homebrew 终端一键安装)**：  
  打开「终端」(Terminal)，执行以下命令：
  ```bash
  brew install blackhole-2ch
  ```
- **方式 2 (直接下载安装包)**：  
  前往 [ExistentialAudio BlackHole 官网/GitHub](https://github.com/ExistentialAudio/BlackHole) 下载 `.pkg` 安装包，双击按提示完成安装。  
  *(安装完成后无需重启电脑，CoreAudio 会自动加载驱动)*

### 步骤 2：在「音频 MIDI 设置」创建「多输出设备」

为了让会议声音**既能输出到您的耳机，又能同时送进 BlackHole 虚拟声卡**：

1. 按 `Command + 空格` 键打开聚焦搜索，输入 **音频 MIDI 设置** (Audio MIDI Setup) 并回车打开。
2. 在窗口左下角点击 **`+`** 号，选择 **创建多输出设备 (Create Multi-Output Device)**。
3. 在右侧设备列表中进行勾选：
   - 勾选 **您的常用耳机或主扬声器**（例如：*MacBook Pro扬声器* 或 *AirPods*）。
   - 勾选 **BlackHole 2ch**。
4. **关键细节配置**：
   - 将 **您的耳机/扬声器** 设为 **主设备 (Master Device)**。
   - 在 **BlackHole 2ch** 一行右侧，勾选 **偏移校正 (Drift Correction)**（保证音频时钟精准同步，不产生破音）。

> 💡 **提示**：可以在左侧列表双击将该设备重命名为「*会议监听多输出*」，便于识别。

### 步骤 3：配置会议软件声音输出

打开您的远程会议软件（如 Zoom、腾讯会议、Microsoft Teams、飞书）：

1. 进入软件的 **设置 -> 音频 (Audio)**。
2. 在 **扬声器 (Speaker / 输出设备)** 下拉菜单中，选择刚才创建的 **多输出设备**（或「会议监听多输出」）。
3. 麦克风 (Microphone / 输入设备) 保持选择您的物理麦克风（如 AirPods 或笔记本内置麦克风），确保会议中其他人可以正常听到您讲话。

### 步骤 4：在同传系统悬浮窗中一键选择输入源

1. 启动同传系统（运行 `启动悬浮同传.command` 或打开 `http://localhost:8000/hud`）。
2. 将鼠标悬浮在 HUD 悬浮窗上方唤起顶栏工具栏。
3. 在音频设备下拉菜单中，选择 **`BlackHole 2ch`**。
4. 后端 `AudioCaptureManager` 将在 **<80毫秒** 内无缝热切换至 BlackHole，无需重启服务，DashScope 云端长连接与字幕显示不中断！
5. 会议中远端发言时，同传窗口即刻实时吐字翻译。

---

### 高级进阶：同时翻译自己和远程同事 (聚集设备)

如果您在会议中既想翻译**远端外宾的发言**，又想翻译**自己对着麦克风说的话**：

1. 打开 **音频 MIDI 设置** (Audio MIDI Setup)。
2. 点击左下角 **`+`** 号，选择 **创建聚集设备 (Create Aggregate Device)**。
3. 在右侧勾选：
   - **MacBook Pro麦克风**（或您的外接麦克风）。
   - **BlackHole 2ch**。
4. 在同传 HUD 的设备下拉框中选择该 **聚集设备 (Aggregate Device)**。
5. 此时麦克风声音与会议软件播放声将自动混合送入同传引擎，实现双向同传！

## 3. Windows 配置指南 (立体声混音 / VB-CABLE)

### 方案 A：使用 Windows 原生「立体声混音」(Stereo Mix)

绝大多数搭载 Realtek 声卡的 Windows 笔记本与台式机均自带硬件级内录功能，无需安装任何额外软件。

#### 步骤：

1. 在任务栏右下角右键点击 **喇叭/音量图标** -> 选择 **声音设置**。
2. 滚动到底部点击 **更多声音设置**（打开经典控制面板「声音」窗口）。
3. 切换到 **录制 (Recording)** 选项卡。
4. 在设备列表空白处右键单击，勾选 **显示禁用的设备** 与 **显示已断开的设备**。
5. 找到 **立体声混音 (Stereo Mix)**：
   - 右键点击并选择 **启用 (Enable)**。
   - 再次右键可选择 **设置为默认通信设备**（可选）。
6. 打开同传悬浮窗顶栏的音频设备选择框，选择 **立体声混音 (Stereo Mix)**。
7. 此时 Windows 正在播放的会议音频即可直接送入同传翻译！

---

### 方案 B：使用通用虚拟音频驱动 VB-CABLE

若某些品牌机或外置声卡屏蔽了「立体声混音」，可使用业界通用的免费虚拟驱动 **VB-CABLE**：

#### 步骤：

1. **下载与安装**：
   - 访问 [VB-Audio 官网](https://vb-audio.com/Cable/) 下载 VB-CABLE 驱动压缩包。
   - 解压后右键管理员运行 `VBCABLE_Setup_x64.exe`，完成安装后重启计算机。
2. **会议软件配置**：
   - 打开 Zoom / 腾讯会议 / Teams，将扬声器输出选择为 **CABLE Input (VB-Audio Virtual Cable)**。
3. **开启监听（让人耳能听到声音）**：
   - 打开 Windows 控制面板「声音」窗口，切换到 **录制 (Recording)** 选项卡。
   - 双击 **CABLE Output** 打开属性 -> 切换到 **侦听 (Listen)** 选项卡。
   - 勾选 **侦听此设备 (Listen to this device)**。
   - 在「通过此设备播放」下拉框中，选择您的**物理耳机或音响**。
   - 点击「确定」保存。
4. **同传系统捕获**：
   - 在悬浮同传窗顶栏中选择 **CABLE Output** 作为音频输入设备。

## 4. 常见问题与故障排查 (FAQ)

### Q1: 在 macOS 上选择「多输出设备」后，按键盘音量键无法调节音量了？

- **原因**：这是 macOS 核心音频（CoreAudio）对多设备聚合通道的系统级行为，当音频同时流向多个物理/虚拟设备时，系统默认禁用全局音量按键。
- **解决方法**：
  1. 在「音频 MIDI 设置」中，确保将**您的物理耳机**勾选为「主设备 (Master Device)」。
  2. 若需调节音量，可在耳机自带线控按键调整，或直接在会议软件内部（如 Zoom 界面中的输出音量滑块）进行调整。

### Q2: 会议结束后，如何恢复为平时日常麦克风？

- 只需在悬浮窗顶部的音频下拉菜单中，重新选择 **MacBook Pro麦克风**（或系统默认麦克风）即可。
- 系统会在 <80ms 内完成无感热切换，无需重启任何程序。

### Q3: 虚拟声卡采集的声音是双声道 (Stereo)，同传支持吗？

- **完全支持**！`server.py` 内置了基于标准库 `array.array('h')` 的**零依赖高速单声道提取与下混算法**，单次下混处理耗时 < 0.005 微秒，CPU 开销为零，会自动将虚拟声卡的多声道实时转换为阿里云所需的 16kHz 16-bit 单声道 PCM。

### Q4: 切换设备后，正在进行的会议翻译会断开吗？

- **绝不断开**！`AudioCaptureManager` 采用**双流交叠并行预打开 + 原子指针替换**架构，只在本地热替换音频硬件流，完全不触碰后台 WebSocket 连接与前端大屏通道，会话与 Token 计费完全平滑保持。
