# Windows 桌面试用版使用说明

适用 Windows 10/11 64 位（x64）。这是 3.7.0 商用前试用构建，不代表已完成所有客户电脑的兼容性认证。

## 安装与首次使用
1. 双击 `HarryTranslateSetup.exe`，阅读许可协议并安装。默认只安装到当前 Windows 用户，无需安装 Python 或 Codex。
2. 如果电脑缺少微软 WebView2，安装器会尝试联网安装；失败会明确停止并提示检查网络。
3. 打开桌面快捷方式，填写百炼 API Key、对应地域和业务空间 ID，点击验证。输入框下方可打开内置六步教程。
4. 验证成功后选择现场对话或远程会议、麦克风，点击检测并说话两秒。检测只在本机进行。
5. 点击开始翻译，进入双栏界面。现场对话模式：中文进入中译英通道，英文也同时供英译中通道处理；实际语言输出仍取决于云模型。
6. 右下角可暂停翻译，或打开“账户与麦克风”重新设置。关闭应用会停止该应用的翻译和采集。

## 会议热词
- 点击顶部“会议热词”。默认分类：未分类、人物姓名、公司机构、产品项目、专业术语。
- “管理分类”可以新增、重命名、停用或删除分类。删除分类只把词条移到未分类，不删除词条。
- 每条词条可设置翻译方向、原词、指定译法、分类、备注和启用状态。
- 分类筛选、搜索、“启用/停用当前筛选”适合为不同会议切换词库。
- 修改需要点击保存。“保存成功”和“云端确认”是不同状态；暂停时会先保存，下次开始翻译再应用。
- 导出保存整个词库（两个方向、分类和本地语音纠错）。导入支持软件导出的 JSON 和原项目的 `glossary.json`。
- 导入前选择合并或替换。合并遇同方向同原词冲突会拒绝，避免悄悄覆盖；替换需要再次确认。导入后仍需保存。
- 多窗口同时编辑时，过期版本保存会被拒绝；可先导出自己的修改，再重新加载。

## 数据在哪里
用户配置、加密密钥、词库和日志位于 `%LOCALAPPDATA%\HarryTranslate`。安装目录与用户数据分离，正常升级和卸载不会主动删除这份数据。卸载后如需彻底清理，先备份词库，再手动删除该目录。

勾选记住密钥时使用 Windows DPAPI 加密；其他电脑或 Windows 用户需要重新输入。未勾选时只在本次运行保留密钥。安装包不会携带开发者密钥或个人词库。

## 仍需了解的限制
- 云端翻译需要联网和有权限、余额/配额可用的百炼账户；充值本身不保证同传模型权限。
- 当前桌面入口开放千问同传模型；Gummy 等未完成此桌面验证流程的模型不作为可切换选项开放。
- 远程会议需要可用的系统声音回环输入；未实现无需回环设备的通用 Windows 系统内录。
- 新包未使用商业代码签名证书，Windows 可能显示未知发布者/SmartScreen 提示。正式对外销售前应完成签名和干净电脑验收，不建议要求客户关闭系统安全防护。
- 原有费用显示为估算，实际扣费以阿里云账单为准；本次没有重做计费算法。
