第一次使用？跟着这 6 步做

不需要写代码，不需要安装 Python，也不用修改配置文件。准备好自己的阿里云账号即可。教程核对日期：2026-11-09；控制台文字可能更新，以官方页面为准。

第 1 步 / 登录阿里云

准备你自己的账号

  1. 点击 打开阿里云百炼控制台，会在浏览器中打开官方网页。
  2. 已有账号：登录。没有账号：点击注册，按网页提示完成注册。
  3. 如果提示实名认证，按照阿里云页面指引完成；如果提示开通百炼服务，阅读并同意其服务协议。

没有弹出开通提示，可能代表已经开通过。不要把账号密码或短信验证码交给别人。

第 2 步 / 选对地域

记住你在哪里创建密钥

在百炼页面右上角找到地域选择。本软件当前提供华北 2（北京）和新加坡。

使用哪个地域创建密钥，回软件时就选择同一个地域。不同地域的密钥不能混用；模型是否开放，以你的账户控制台和软件验证结果为准。

例如：网页选“华北 2（北京）” → 软件也选“华北 2（北京）”。
第 3 步 / 创建密钥

找“API Key”，不是“AccessKey”

  1. 进入百炼的 API Key 管理页面。入口位置若不同，可使用官方“获取 API Key”教程中的控制台直达链接。
  2. 点击创建 API Key。
  3. 选择归属账号和业务空间。个人试用通常使用自己的主账号和默认业务空间；公司子账号若无权限，需要管理员授权。
  4. 模型权限必须允许调用 qwen3.8-livetranslate-flash-realtime。若使用自定义权限，请检查该模型已被允许。
  5. 创建成功后，立即点击复制，保留完整密钥。新版密钥一般只在创建时完整显示一次。

带“…”的脱敏文字不是完整密钥。若没保存，请重置或重新创建。不要把密钥发到群里或截图公开。

第 4 步 / 找到业务空间 ID

新版业务空间用户还要复制这项

在百炼的业务空间管理中找到刚才创建密钥所属的空间，复制它的业务空间 ID / WorkspaceId。不要复制空间名称，也不要把整段网页地址粘贴进去。

返回软件后将 ID 填入“业务空间 ID”框。仍使用旧版通用 DashScope 接入的账户可以先留空；如果验证失败并且控制台给的是业务空间专属接入地址，请按该空间填写。

第 5 步 / 回到软件验证

粘贴 → 选择地域 → 验证

  1. 点击页面上方“返回软件”。在 API Key 框粘贴刚才复制的完整密钥。
  2. 选择相同地域，按需要填写业务空间 ID。
  3. 自己的电脑可以勾选“记住密钥”；公共电脑建议取消。
  4. 点击验证 API Key 并继续。看到“验证成功”后才继续。

这一步只检查连接与同传会话，不录音，也不上传会议声音。充值成功不代表地域、模型权限一定配置正确。

真实翻译会产生阿里云模型调用费用。请在阿里云账户检查余额、欠费状态和模型配额；实际费用以阿里云账单为准。

第 6 步 / 选麦克风并试说

看到声音，再开始翻译

  1. 面对面中英交流，选择现场对话。
  2. 使用笔记本自带麦克风时，优先选择麦克风阵列；用耳机时选择对应耳机麦克风。
  3. 点击“检测麦克风”，说“你好，欢迎参加会议”。看到检测到声音后，点击开始翻译，进入系统。
  4. 再说一句英文，例如“Welcome to our meeting.”，观察右侧中文译文。

远程会议需要额外选择“系统声音输入”。列表没有可用回环设备时，本版本无法直接采集对方声音；请不要随便选一个麦克风当系统内录。

遇到问题，先看这里

看到什么怎么做
密钥无效重新复制完整密钥，检查没有空格、“…”或换行；核对地域和空间。
模型无权限 / 找不到模型在该地域的百炼控制台检查同传模型开放情况和 Key 权限。普通文本模型能用，不代表同传模型一定能用。
余额、额度或限流检查阿里云账单、欠费和模型配额；稍后再试，不要连续点击验证。
无法连接先确认电脑能联网；公司网络可能需要管理员允许访问阿里云实时服务。
麦克风没声音检查硬件静音开关；Windows 设置→隐私和安全性→麦克风→允许桌面应用访问。
记住密钥后换电脑不能用本机加密保护与 Windows 用户相关。请在新电脑重新填写，不要复制加密文件。
